# English Digital Storytelling App

Ini adalah repository pusat untuk proyek EDSA. Sejarah pengembangan proyek ini dibagi menjadi beberapa versi yang diarsipkan dalam branch terpisah:

* **[v1](https://github.com/ipincamp/edsa-api/tree/v1)**: Versi 1 (Maret 2025 - Juli 2025). Dibangun menggunakan Laravel 12.
* **[v2](https://github.com/ipincamp/edsa-api/tree/v2)**: Versi 2 (Juli 2025 - Agustus 2025). Lanjutan dari v1, masih menggunakan Laravel 12.
* **[v3](https://github.com/ipincamp/edsa-api/tree/v3)**: Versi 3 (Oktober 2025). Penulisan ulang total (rewrite) menggunakan Go (Fiber) & PostgreSQL.

Branch `main` ini hanya berfungsi sebagai halaman utama dan dokumentasi.
